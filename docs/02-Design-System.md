# 山海城市志 / The Valdora City Atlas

## 核心概念

打开一部数字时代的城市建筑志。封面先让真实城市与名字建立印象，接着用总图解释结构，再走近一座建筑，最后从白昼走入夜色并进入世界。

## 访客路径

1. 封面字标、山海实景、世界尺度与入城入口。
2. 全域影像 → 真实坐标总图 → 选择城区 → 理解空间序列。
3. 五座住宅图鉴与36原型完整目录 → 四个大型地标展页。
4. 七段山海旅程 → 操作导览 → 五组昼夜影像 → 八份卷轴悬念。
5. 生成和渲染技术 → 十张城市影像 → 创作理念 → 夜色入城。

Typography：Georgia / Times 与宋体系列负责大标题；Segoe UI / Microsoft YaHei / PingFang 负责正文与导航。字体全部系统回退，不依赖第三方字体请求。

品牌图形以三点王冠、城墙横线和海浪线组成矢量标记。留白、细线、档案编号、取景标签代替圆角卡片。页面遵循不对称图文、整版影像、序列图鉴与深浅章节交替。

## 交互

- 原生锚点、章节高亮、移动目录与 Escape 关闭。
- 规划图区域悬停/点击；对应按钮支持键盘与触屏；全域/主城切换。
- 建筑图鉴循环翻页，完整36原型目录可展开。
- 地标链接携带真实相机参数进入原城市副本。
- Journey 使用 IntersectionObserver；只有淡入淡出的影像层，不运行额外 WebGL。
- 昼夜滚动按区间切换，手动选时后尊重用户选择。
- Gallery 分类、原生 dialog 灯箱、左右键翻页、Esc、焦点恢复。
- Reduced Motion 下取消平滑滚动、淡变和超长 sticky 旅程，保留可点选的七站体验。

## 移动设备

独立安排封面高度、双列数据、展开目录、城区选择、建筑图鉴、画廊与技术段落。地标变为大图在上、正文在下；图库重新采用纵图与跨列横图。375/390/430均单独检查，包含1024平板与三种桌面尺寸。

## 主动不做

1. 不把原城市藏进持续渲染的官网背景；先展示轻量实景，再由访客主动入城。
2. 不用现实欧洲图库或生成城堡代替瓦尔多拉。
3. 不采用SaaS式卖点卡片、购买漏斗、粒子装饰和云存档话术。

## 工程

Vite + React + TypeScript。组件、章节、数据、hooks、样式、截图与QA脚本分离。图库灯箱动态导入，图片按需加载、响应式WebP。源城市只做字节一致的独立副本。
